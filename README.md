# JTEC Electrical Services website

Company profile website for **JTEC Electrical Services** and its solar division, **JTEC Solar Installation**
(Linao, Pura, Tarlac). All content comes from the JTEC company profile (2026), with **Robert S. Mallillin,
Assistant Manager** added to the team at the client's request.

The art direction, and the reason behind each visual decision, is in [DESIGN.md](DESIGN.md).

## Pages

| Route | What it holds |
| --- | --- |
| `/` | Hero with the live 3D hybrid-system diorama, introduction, services, installation log, Luzon map, team, night footer |
| `/services/` | The five services in full, how a project runs, hybrid versus grid-tied |
| `/projects/` | All 14 installations to scale and photographed (filterable), map of job sites |
| `/about/` | Story, mission and vision, six values, ten commitments, team and crew, electrical work since 2016 |
| `/contact/` | Quotation request form, direct contact, office location |
| `404` | "This circuit is open." |

## Stack

- [Astro](https://astro.build) 7, static output, TypeScript
- [Three.js](https://threejs.org) for the hero diorama (lazy-loaded on the home page only)
- [GSAP](https://gsap.com) with ScrollTrigger for entrances and scroll-linked details
- Archivo variable font, self-hosted through Fontsource
- No backend, no trackers, no third-party requests at runtime

## Working on it

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev        # http://localhost:4321
npm run check      # type and template check
npm run build      # static site in dist/
npm run preview    # serve the build locally
```

## Deploying

`npm run build` produces a static site in `dist/` that any static host can serve (Vercel, Netlify,
Cloudflare Pages, GitHub Pages, or plain shared hosting). Set `SITE_URL` (for example
`SITE_URL=https://www.example.ph npm run build`) so canonical and Open Graph URLs are absolute.

## Editing content

| To change | Edit |
| --- | --- |
| Phone, email, address, mission, vision, values, commitments, project steps | `src/data/site.ts` |
| Services and their photos | `src/data/services.ts`, `src/assets/services/` |
| Installation log (sizes, batteries, places, dates, photos) | `src/data/projects.ts`, `src/assets/projects/` |
| Team, roles, portraits, work experience | `src/data/people.ts`, `src/assets/team/` |
| Map positions | `src/data/places.json`, then `npm run map` |

Adding an installation: put two photos in `src/assets/projects/` as `<slug>-a.jpg` and `<slug>-b.jpg`, add
an entry to `projects` in `src/data/projects.ts`, and, if the place is new, add it to `places.json` and run
`npm run map`. The total kWp, the chart, the table and the map update themselves.

Team portraits are square PNG cutouts framed so that every head is the same size and height; keep new
portraits in the same framing.

### Quotation form

There is no form backend. "Write the request email" validates the form and opens the visitor's email app
with the request written out to the address in `src/data/site.ts`, and shows a copyable version in case
no email app opens. Without JavaScript the form still posts to the same address through `mailto:`. To use a
form service later, replace the submit handler in `src/components/QuoteForm.astro`.

## Assets

- Photographs, team portraits and the logo come from the company profile PDF. The logo was traced into
  layered SVG (`src/assets/brand/`, `public/brand/jtec-logo-sprite.svg`) so it can follow light and dark
  sections.
- Robert S. Mallillin's portrait was cut out of its studio background and framed to match the others.
- The hero poster (`src/assets/hero/hero-poster.jpg`) is a render of the 3D scene at 7:30 AM. It shows
  while the scene loads and replaces it when WebGL or JavaScript is unavailable. If the scene changes,
  render a new one at that time of day and keep the hero's starting colour (`--bg` on `.hero`) in sync.
- Map outlines: Natural Earth 1:10m countries and lakes (public domain), generated by `scripts/build-map.mjs`.

## Accessibility and quality checks

Checked on the production build in Chromium at 1440, 1280, 1024, 834, 390 and 360 px wide:
no console errors, no horizontal overflow, one `h1` per page, headings of two lines or fewer, all
images with `alt` text and dimensions, all internal links and anchors resolving, and no axe-core
(WCAG 2.2 AA and best-practice) violations. Every interactive element was exercised (time-of-day slider
by keyboard, play and pause, service and log previews, map zoom and highlights, project filters with the
empty state, chart tooltips, the mobile menu with Escape, form validation and the written request,
navigation), plus `prefers-reduced-motion` and JavaScript-disabled visits.

## Before launch

- Set `SITE_URL` to the production domain.
- Confirm the contact email (currently the Gmail address from the profile) and phone number.
- Confirm permission to publish every photograph and portrait.
- The map places points at approximate town and barangay centres; adjust `places.json` if needed.
